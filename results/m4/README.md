# Milestone 4 results

Every table here is written by a script in [`../../src/`](../../src/) (seed 5502), on the
same leave-one-day-out folds, 64 features and 1% benign alert budget as Milestone 3.
Nothing in this folder contains flow records. The per-flow score files
(`m4_anomaly_scores.npz`, `m4_supervised_scores.npz`) are regenerated by the scripts and
are not committed.

| File | Written by | Contents |
| --- | --- | --- |
| `m4_anomaly_fold_metrics.csv` | `m4_anomaly.py` | Isolation Forest and PCA reconstruction error per held-out day: training condition (A = other four days; B = plus the held-out day's other-half benign flows), test set (full day / common half), all vs. defect-free flows, counts, recall, false-alarm rate, precision, PR-AUC, chosen settings |
| `m4_anomaly_per_class.csv` | `m4_anomaly.py` | Recall per attack class under the same breakdown |
| `m4_anomaly_tuning.csv` | `m4_anomaly.py` | Inner leave-one-day-out PR-AUC for every detector setting |
| `m4_refit_check.csv` | `m4_importance.py` | Refit gradient boosting and random forest vs. the Milestone 3 numbers (reproducibility check) |
| `m4_importance_single.csv` | `m4_importance.py` | Permutation importance on each unseen attack day, one feature at a time: drop in PR-AUC and in recall at the fixed threshold |
| `m4_importance_groups.csv`, `m4_feature_groups.json` | `m4_importance.py` | The same with near-duplicate features (\|Spearman ρ\| ≥ 0.9) shuffled together, and the 33 groups' members |
| `m4_rf_robustness.csv`, `m4_rf_robustness_per_class.csv` | `m4_importance.py` | Random forest with seeds 1–3 and without `Init_Win_bytes_forward/backward` |
| `m4_hybrid_fold_metrics.csv`, `m4_hybrid_per_class.csv` | `m4_hybrid.py` | Classifier OR Isolation Forest under one shared 1% budget, with counts of attacks caught by each part |
| `m4_summary_pooled.csv`, `m4_summary_by_day.csv` | `m4_figures.py` | The summary tables quoted on the website and in the final report |
| `*_run_log.txt` | each script | Timed run logs |
