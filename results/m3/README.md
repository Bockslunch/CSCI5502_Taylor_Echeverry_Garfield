# Milestone 3 results

Every table here is written by a script in [`../../src/`](../../src/) (seed 5502). Nothing in
this folder contains flow records; the per-flow score file (`rq4_scores.npz`, ~23 MB) is
regenerated by `m3_rq4_transfer.py` and is not committed.

| File | Written by | Contents |
| --- | --- | --- |
| `rq4_fold_metrics.csv` | `m3_rq4_transfer.py` | One row per model × held-out day × training condition (A/B/C) × test set: counts, recall, false-alarm rate, precision, F1, PR-AUC, ROC-AUC, threshold, chosen hyperparameters |
| `rq4_per_class.csv` | `m3_rq4_transfer.py` | Recall for each attack class under the same breakdown |
| `rq4_tuning.csv` | `m3_rq4_transfer.py` | Inner leave-one-day-out PR-AUC for every hyperparameter setting |
| `rq4_features_used.json` | `m3_rq4_transfer.py` | The 64 model features, the excluded columns and why, the 1% false-alarm target |
| `rq4_run_log.txt`, `rq4_stdout.txt` | `m3_rq4_transfer.py` | Timed run log; raw output including logistic-regression convergence warnings from inner tuning |
| `rq5_defect_counts.csv` | `m3_rq5_defects.py` | Defect flags per class (zero-payload web attack, timeout-capped, shared feature vector) |
| `rq5_fold_metrics.csv`, `rq5_per_class.csv` | `m3_rq5_defects.py` | Defects retained vs. excluded, scored on all vs. clean test flows |
| `rq2_cv_metrics.csv`, `rq2_per_class_f1.csv`, `rq2_confusion_V2.csv`, `rq2_importance.csv` | `m3_rq2_separability.py` | 11-class separability (three feature variants, two baselines), per-class F1, confusion matrix, permutation importance |
| `rq2_transfer_no_artifacts.csv` | `m3_rq2_separability.py` | RQ4 gradient-boosting transfer without the `Init_Win_bytes_*` fields |
| `m3_errors_*.csv` | `m3_error_analysis.py` | Profiles of false alarms and missed attacks, false-alarm ports, benign score quantiles |
| `m3_stability.csv` | `m3_stability.py` | Held-out recall for four random seeds per attack day |
| `rq4_forest.csv` | `notebooks/05-random-forest.ipynb` | Random forest on every held-out day (seed 5502) and on Tuesday with seeds 1–3: counts, recall, false-alarm rate, precision, PR-AUC, per-class recall |
| `m3_summary_*.csv` | `m3_figures.py` | The summary tables quoted on the website and in the report |
